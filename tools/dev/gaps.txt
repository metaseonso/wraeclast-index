  Why each gap stays (every name the game has and no card carries has one reason):

  · gems, 1: a slot the game holds open for a gem that is not in it yet (Coming Soon)
  · gems, 1: the stand-in the game shows where a skill was taken out (Removed Skill)
  · notables, 5: a choice notable: no effect of its own, and each option it offers is a card (Brew
    Concoction, Implanted Gems, Lucid Dreaming, Path Seeker …)
  · small passives, 68: an icon-only node (a mastery or a blank plate): no effect to show (Accuracy
    Mastery, Armour Mastery, Armour and Energy Shield Mastery, Armour and Evasion Mastery …)
  · small passives, 34: where an ascendancy starts on its wheel: no effect to show (Acolyte of Chayula,
    Amazon, Arcane Archer, Assassin …)
  · small passives, 6: a class's starting plate on the tree: no effect to show (DUELIST, MARAUDER,
    RANGER, SIX …)
  · keywords, 1: the game's own placeholder, "This test case is designed to be overwitten" (Test)
  · currency, 7: the game's own text says it is no longer usable (Black Scythe Artifact, Broken Circle
    Artifact, Exotic Coinage, Order Artifact …)
  · currency, 1: no text anywhere in the game files for it (poe2db shows none either) (Omen of
    Recombination)
  · areas, 85: a hideout: a player's own place, not the world (All at Sea Hideout, Alpine Plateau
    Hideout, Ancestral Hideout, Arcane Isle Hideout …)
  · areas, 9: a developers' test area (All Black, Boss Rush Area 1, Boss Rush Area 2, Boss Rush Area 3
    …)
  · areas, 9: a screen or a heading, not a place (character select, an act's title) (Act 1, Act 2, Act
    3, Act 4 …)

  game: the export, minus the names players never see ([DNT] markers, names the game fills in).
  Bases and currency count the official trade site's lists instead (data/trade.json): the export
  still marks hundreds of old and unused items released.

  · 1086 items have official text in data/info.json and 337 of them get no card — but only 7 of those
    are on the trade site's list today. The rest are old items the export still carries.
  · 239 base items grant a skill; we card 201 of them and name the skill on 201. The other 38 are not on
    the trade site's list.
  · 442 areas in the game files are 288 places in data/areas.json (38 more merged into a place of the
    same name); 116 are hidden on purpose (5 [DNT], 92 hideout, 1 no name, 9 not a place, 9 test). No
    card kind draws them yet (design/areas.md).
  · The drill-down page lists 28 timeless jewel lines. data/jewels.json (tools/gamelib.py) holds the
    Jewel kind's data: 9 jewel bases, 7 timeless factions and 23 conquerors; the card kind itself is
    proposed in design/gems-gaps.md.
  · 7 of the 24 export files no tool reads, each for a reason:
  · active_skill_types.min.json: the names of the skill types; skills.min.json already names every
    skill's types, and the gem cards draw the game's own tag names (gem_tags) instead.
  · audio.min.json: the sound each thing plays; the site plays none.
  · cost_types.min.json: what each skill cost is paid in and how the game writes it; skills.min.json
    already names the resource on every cost the gem cards show.
  · stat_value_handlers.min.json: how a stat description turns a number before it is shown (negate, per
    minute to per second); the few the tree uses are applied in tools/tree.py (Wording), and every other
    line comes already worded in the export.
  · stats_by_file.min.json: which description file words each stat; the tools read the two files the
    items and the tree are worded from, in the game's order, and never need to look one up.
  · tag_details.min.json: the display names of the spawn tags; no card shows a spawn tag.
  · tags.min.json: the spawn tags items and modifiers roll by; tools/craft.py reads them straight off
    each base and modifier, and they are never shown.
